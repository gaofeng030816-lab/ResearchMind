## 真实论文抽查

样本：[Attention Is All You Need](https://arxiv.org/pdf/1706.03762)，arXiv:1706.03762v7。

- 15/15 页提取到非空文本。
- 页面图像在 1.5 倍缩放下渲染清晰；首页和包含 Scaled Dot-Product Attention 公式的第 4 页已做视觉检查。
- `Multi-Head Attention` 块级搜索返回 8 个命中。
- PDF 未提供可用的 title/author 元数据，因此标题按设计回退为文件名，作者列表为空。

## 已知局限

- 数学公式按普通 PDF 文字绘制顺序提取，不保留二维结构。例如分式的分母可能出现在公式行尾；V1 不做公式识别。
- 双栏阅读顺序依赖 PDF 内部文字对象顺序与 PyMuPDF 的排序结果；本样本正文可读，但不能保证所有排版复杂的论文都正确。
- 图中的标签可能被提取为零散文本，但图像语义、表格结构和公式结构不会被识别。
- 扫描版 PDF 没有文字层时会得到空文本；OCR 明确不在 V1 范围内。
- 页面 PNG 是视觉对照，V1 不提供页面级高亮、批注或精细划词。
