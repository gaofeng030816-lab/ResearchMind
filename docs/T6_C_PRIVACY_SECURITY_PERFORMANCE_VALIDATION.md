## 2. 隐私与权限审计

只读源码检查结果：

- `src/researchmind/` 无 `subprocess`、`os.system`、`shell=True`、`eval`、
  `exec` 或 `Popen`；
- 后续 T5-B1 的唯一源码写入点是 `code/change_writer.py`；它只做恢复副本、
  hash-safe 原子替换/回滚，不执行 Shell、源码、测试或安装；

- `.env`、`.env.*` 和 `.streamlit/secrets.toml` 均被 Git 忽略；
- 已有自动化继续覆盖 Prompt Injection、无参数工具白名单、预算、未知/重复
  动作停止、绝对代码路径省略、PDF/代码/Vault 路径越界和备份归档攻击。

本轮没有调用真实 LLM、读取真实代码仓库或写真实 Vault。
