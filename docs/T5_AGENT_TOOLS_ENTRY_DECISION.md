# T5 受限智能助手进入决策

日期：2026-08-29
状态：Approved and Completed（用户已确认 T5-A 推荐方案）
前置：T0–T4 Completed

## 1. 为什么需要单独确认

T5 会让模型不只回答一次问题，而是在有限步骤内请求应用提供额外证据。即使
首个切片只读，这也会改变 LLM 协议、调用次数、费用、提示注入攻击面和用户对
“这个软件是否内置 Agent”的理解。因此，之前“按门禁推进到 V2”的授权不能替代
具体工具权限确认。

## 2. 推荐最小方案：T5-A 只读研究助手

### 2.1 工具清单

只提供三个无参数、当前会话限定的只读工具：

| 工具 | 返回内容 | 明确不做 |
|---|---|---|
| `inspect_paper_context` | 当前选择对应的有界 ResearchContext 和 provenance | 不打开任意路径，不发送整篇 PDF |
| `inspect_code_context` | 当前 CodeSelection 对应的有界 CodeContext | 不读未选择文件，不执行/修改代码 |
| `inspect_evidence_links` | 当前会话 EvidenceLink 摘要和双方 locator | 不创建、修改或猜测链接 |

没有 shell、测试运行、依赖安装、任意文件读取、代码/Vault 写入、删除、网络抓取
或系统命令工具。T5-A 不改变现有 `LlmProvider` 的普通解释路径。

### 2.2 交互与确认

1. 用户输入一个明确问题并看到可用工具、外发范围和最多步骤；
2. 点击“开始只读助手”才进行第一次 LLM 调用；
3. 模型一次只能请求一个白名单工具或给出最终回答；
4. 应用本地执行只读工具后显示工具名、来源、字符数和状态；
5. 用户每次点击“继续”才把该工具结果发送给模型，可随时停止；
6. 最多 3 次工具调用、4 次 LLM 调用；重复工具/参数、非法动作或预算越界立即
   停止；
7. 最终回答保存在独立助手会话状态，不自动写 Conversation、KnowledgeNote、
   Vault 或代码。

读工具在用户启动后不逐次弹高影响确认，因为它们只读取当前已打开、已选择、
已预览的会话证据；每次新的网络调用仍需用户点击“继续”。未来任何写入或执行
工具必须另开 T5-B 权限决策，不能沿用本批准。

### 2.3 协议与沙箱

- 用严格、版本化的文本动作协议，而不是允许模型提供 Python/命令：
  `inspect_paper_context` / `inspect_code_context` /
  `inspect_evidence_links` / `final`；
- 解析器拒绝未知字段、参数、多个动作、超长输出和协议外文本；
- 工具调度是固定 Python 白名单（当前实现为显式 `if/elif` 分支），不接受
  动态 import、反射、`eval`、`exec` 或模型生成 callable；
- 工具只调用现有 use case/core 构建器，不直接访问任意文件路径；
- 论文、代码、链接和历史继续作为不可信数据分隔，工具结果不能改变系统指令；
- 整个流程在现有单进程 Streamlit 应用内，不新增服务、数据库或后台 worker。

### 2.4 预算、审计与停止

- 工具调用上限：3；
- LLM 调用上限：4；
- 每个上下文沿用现有 token budget，工具总返回量再设硬上限；
- 会话内审计记录：步骤、模型请求动作、实际工具、状态、输入/输出字符数、
  时间、停止原因；不记录 API Key 或完整敏感 payload；
- 停止原因包括：用户停止、final、非法协议、未知工具、重复循环、预算耗尽、
  provider 失败或工具失败；
- 刷新/打开新来源时助手状态失效；不跨会话持久化。

## 3. T5-A 成功标准

1. 用户能对当前论文、代码和已确认链接提出一个综合问题；
2. 模型只能从三个只读白名单工具中逐步请求证据；
3. UI 在每次继续前展示动作与审计，不存在隐藏自动循环；
4. 恶意论文/代码文本不能请求 shell、文件写入或未知工具；
5. 超过步骤、字符或 token 预算可预测地停止；
6. provider/tool 失败不会污染原有 Conversation、KnowledgeNote、链接或源码；
7. fake provider 的协议、注入、越权、循环、预算、停止和恢复测试通过；
8. V1.3.2 + T1/T3/T4 全量回归继续通过。

## 4. 本次确认不会授权

- shell、PowerShell、终端或测试执行；
- 写入/修改/删除代码、PDF、Vault 或任意文件；
- 安装依赖、联网搜索、Git 操作或 VS Code 控制；
- 模型自动创建 EvidenceLink 或把推断标成事实；
- 后台自主运行、无限循环、跨会话任务或无人确认的连续网络调用；
- T6 发布、UI 重写、数据库或最终版本号。
